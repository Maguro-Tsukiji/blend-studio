# Bundled assets

These assets were created for Blend Studio and are distributed under the project's [MIT license](../LICENSE). They do not include the private avatar models used during local development.

| File | Origin |
|---|---|
| `logo.svg` | Project-authored purple geometric logo; shared by the app and plugin metadata |
| `studio-companion.glb` | Procedural Studio Companion sample generated by `scripts/create-demo.mjs` |
| `demo-base64.json` | Base64 copy of that GLB generated by the same script for the offline viewer |
| `textured-test.blend` | Procedural cube with a packed checker texture, created by `tests/create-blend-fixture.py` |
| `humanoid-test.blend`, `humanoid-test.glb` | Original procedural T-pose figure with 17 weighted bones and a front visor, created by `scripts/create-humanoid-fixture.py` |
| `wave-test.vrma` | Original two-second arm wave and hips translation, created by `scripts/create-vrma-fixture.mjs` |

Regenerate the GLB and embedded copy with:

```sh
node scripts/create-demo.mjs
```

Regenerate the Blend fixture from the repository root using your Blender executable:

```sh
blender --background --factory-startup --python tests/create-blend-fixture.py -- assets/textured-test.blend
```

Regenerate the motion fixtures from the repository root:

```sh
blender --background --factory-startup --python scripts/create-humanoid-fixture.py -- assets
node scripts/create-vrma-fixture.mjs
```

Open the humanoid Blend or GLB in the viewer, then load the VRMA to check playback. These fixtures and their motion were authored for this project and contain no third-party avatar data.

The README screenshot in `docs/images/surface-point.png` shows this project's Studio Companion in the viewer. All third-party models/textures loaded by users retain their own ownership and licensing.

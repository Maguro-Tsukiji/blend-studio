# Manifest schemas

`plugin.schema.json` and `mcp.schema.json` are unmodified copies of the Agent Plugins specification 1.0.0 schemas. They are vendored so packaging does not need to fetch a schema from the network or depend on files outside this repository.

- [Plugin schema](https://agent-plugins.org/schemas/1.0.0/plugin.schema.json)
- [MCP schema](https://agent-plugins.org/schemas/1.0.0/mcp.schema.json)
- [Upstream specification repository](https://github.com/agentplugins/agent-plugins-spec)
- [Upstream licensing policy](https://github.com/agentplugins/agent-plugins-spec/blob/main/LICENSE.md)
